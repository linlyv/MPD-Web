ADB 指令手册与示例

先在“当前设备”选择目标设备。下方命令只填写 ADB 子命令，不要加 adb -s 设备地址。点击“填入”可把示例放进自定义命令框，仍需点“执行”。

shell：在电视上运行系统命令

查看型号、下载目录、Android 版本或已安装应用。查询列表通常会输出很多行。

shell getprop ro.product.model
shell ls -lah /sdcard/Download
shell pm list packages -3
shell monkey -p com.phlox.tvwebbrowser 1

install / uninstall：安装或卸载应用

路径指运行网页的 iStoreOS 主机路径，不是浏览器所在电脑路径。卸载会移除应用；确认包名后再执行。

install -r /root/mpd/tvbro.apk
uninstall com.phlox.tvwebbrowser

push / pull：在 iStoreOS 与电视间传文件

push 的第一个路径在 iStoreOS，第二个在电视；pull 顺序相反。网页上传的 APK 可直接用上面的“上传并安装”。

push /root/mpd/tvbro.apk /sdcard/Download/tvbro.apk
pull /sdcard/Download/tvbro.apk /tmp/tvbro.apk

logcat / reboot：日志和重启

logcat 取最近日志；reboot 会重启电视并断开 ADB，设备启动后需重新连接。

logcat -d -t 200
reboot
安全与兼容性：shell 命令会在电视执行；不要输入来源不明的命令。R1 的 `pm` 查询可能返回 `error: closed`，可在 iStoreOS SSH 终端运行 `adb -s R1地址 shell dumpsys package > /tmp/r1-package-dump.txt` 获取应用信息。ADB 1.0.32 可能不支持无线调试配对；不要将 ADB 端口暴露到公网。
请确认电视和 iStoreOS 在同一可互通局域网、电视已开启网络调试并授权。ADB 自定义命令最长 1024 个字符；执行超时为 20 秒。
